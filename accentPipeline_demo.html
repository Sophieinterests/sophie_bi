Grandma's Voice – Accent-Aware Speech-to-Text

Off-the-shelf voice-to-text kept mishearing my grandparents' Wendeng-accented Mandarin. So I built a pipeline that collects their speech and fine-tunes a Whisper model to understand them.

The Problem

Speech models are trained on "standard" accents
My grandparents speak Mandarin with a strong Wendeng (Shandong) accent. Generic speech-to-text tools return garbled transcripts, which makes voice messages, search and assistants frustrating for exactly the people who benefit most from not having to type.

Step 1: Prompts Grandma Enjoys Reading

Claude API Topic-based text generation
Grandma picks a topic (问候语 greetings, 养生 health, 感悟 reflections, 故事 stories, 回忆 memories) and the app generates an 80–150 character passage in warm, everyday language with no rare characters. It reads like a WeChat morning greeting, so recording sessions feel like a chat rather than a chore.

Step 2: Elder-Friendly Recorder

Design principle: Big buttons, one action at a time
The interface is entirely in Chinese with three large controls: 换一段 (new passage), 开始录音 (start), 停止录音 (stop). A session counter shows progress so we can see the dataset grow.

Step 3: Human-in-the-Loop Labels

Data quality Transcript matches what was actually said
The generated text pre-fills the transcript, and I edit it wherever grandma skipped, added or changed words. Every audio clip is paired with an accurate label, which matters a lot when the dataset is small.

Step 4: Dataset Storage

Node / Express + Google APIs
On upload, the audio goes to a Google Drive folder and a row (timestamp, filename, transcript, Drive link, file size) is added to a Google Sheet. The sheet then becomes the training manifest.

Step 5: Fine-Tuning Whisper

Whisper-medium + LoRA (PEFT) Efficient training on a small dataset
Rather than retraining the whole model, I use LoRA adapters (r=32) on the attention projections, trained with Hugging Face's Seq2SeqTrainer on grandma's audio/transcript pairs. This adapts Whisper to her accent without needing thousands of hours of data.
